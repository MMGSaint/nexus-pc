# NEXUS Grok Build skills

Reusable operating knowledge for Grok Build. Skills are discovered from `.grok/skills/` in this repository and from the user skill store.

Do not paste these methodologies into every master prompt. Describe the current task; route through `nexus-orchestrator` for non-trivial work.

Specialists:
- `nexus-orchestrator`
- `nexus-architect`
- `nexus-telemetry`
- `nexus-control`
- `nexus-optimizer`
- `nexus-learning`
- `nexus-safety`
- `nexus-benchmark`
- `nexus-research`
- `nexus-provenance`

Optional slash-style prompts live in `.grok/prompts/`.

These skills describe how to work on NEXUS. They are not runtime code and they do not grant actuation authority.
